# BKT Graph Adaptive Testing (v1.1)

Исследовательский проект: «Разработка динамической графо-байесовской математической модели адаптивного обучения для оптимизации подготовки учащихся 5–6 классов к экзаменам повышенной сложности»
- **Секция:** Прикладная математика
- **Автор:** Марат Ілияс (10 класс, Областной лицей-интернат для одарённых юношей, г. Экибастуз)
- **Руководитель:** Узбеков Олжас Оразович

## Описание
Интерактивный программный прототип на базе модифицированного алгоритма Bayesian Knowledge Tracing (BKT v1.1). Модель включает конъюнктивную логику Noisy-AND, динамическое угадывание с элиминацией дистракторов и оптимизатор выбора заданий на основе Expected Information Gain (EIG).
